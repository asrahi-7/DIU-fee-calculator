# DIU CSE Semester Fee Calculator 🎓

A modern, sleek, and interactive web application designed for students of the Department of Computer Science and Engineering (CSE) at Daffodil International University (DIU). This tool helps students accurately calculate their final exam clearance fees by factoring in core credits, GED credits, labs, retakes, waivers, and previously paid installments.

## ✨ Features

- **Glassmorphism UI:** A beautiful, frosted-glass design aesthetic with an animated gradient background.
- **Smart Waiver Logic:** Automatically applies waiver percentages to regular courses while properly excluding retake credits (as per university policy).
- **Course Reference Guide:** A built-in modal containing a quick reference list of common GED and Core courses.
- **Real-time Feedback:** Smooth scrolling and fade-in animations when generating the final calculation breakdown.
- **Fully Responsive:** Works perfectly on desktop, tablet, and mobile devices.

## 🚀 Enhancements & VFX (New Update)
- **Floating Particles Effect:** Added animated background shapes for a dynamic, modern visual experience.
- **Neon Glow Interactions:** Enhanced input fields and buttons with glowing drop-shadows on hover/focus.
- **Number Counting Animation:** The final payment amount now dynamically counts up to the total value for a satisfying user experience.
- **3D Hover States:** Buttons now scale and emit a colored glow when interacted with.

## 🛠️ Technologies Used
- **HTML5:** Structure and semantics.
- **CSS3:** Flexbox/Grid, CSS Animations, Glassmorphism techniques, and FontAwesome icons.
- **Vanilla JavaScript:** DOM manipulation, math logic, and custom animations (no external libraries required).

## 💻 How to Use
1. Download or clone this repository.
2. Double-click `index.html` to open it in your preferred web browser.
3. Input your current semester's credits (Core, GED, Lab).
4. Enter any retake credits if applicable.
5. Adjust fee rates or installment amounts if they have changed.
6. Enter your waiver percentage.
7. Click **"Calculate My Final Payment"** to see the detailed breakdown.
